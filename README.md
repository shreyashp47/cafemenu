# CafeMenu

QR ordering for any small cafe, built from
[TOE](https://github.com/shreyashp47/TOE). A cafe fills a form, connects its own
Firebase project, and gets its own ordering website. CafeMenu keeps it updated
with new releases the owner chooses.

Nothing is built yet. Start with the [plan](./PLAN.md); the work is tracked in
[issues](https://github.com/shreyashp47/cafemenu/issues), one
[milestone](https://github.com/shreyashp47/cafemenu/milestones) per phase.
